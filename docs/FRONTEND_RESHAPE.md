# 前端操作重整

2026-10-13，依使用者回饋與 `frontend-design` skill 實作；本文件更新原 UI/UX 方案的畫面配置，API、安全與資料規則沿用。

## 設計前的判斷

舊版把研究報告當成首頁，候選只能逐檔閱讀，沒有資料比較工具。此次優先解決選股研究的三個動作：找候選、比較財務數據、查證後追蹤。

- 色彩（同日競品參考後更新）：畫布 `#F5F7FA`、紙面 `#FFFFFF`、文字 `#182230`、次要文字 `#526173`、操作深藍 `#2457C5`。品牌雷達保留深綠；證據支持、收藏、風險採不同視覺語意，詳見 [色彩重整紀錄](FRONTEND_VISUAL_REFRESH.md)。
- 字體（Apple design 精修後）：平台系統字體優先、PingFang TC / Microsoft JhengHei 中文 fallback；數值等寬對齊，依層級調整字重、行高與字距。字級使用 rem，主標題 1.875rem、正文 1rem，細節見 [視覺調整紀錄](FRONTEND_VISUAL_REFRESH.md)。
- 版面：左側穩定導覽，首頁全寬候選表，文字靠左、財務數值靠右。個股深入閱讀另開完整工作區，避免列表擠壓研究。
- 特徵：把營收、獲利、負債與流動性放在同一條股票列中；比較面板沿用相同指標順序。使用來源實際日期，沒有假行情、假價格、假走勢。

```
導覽 | 選股研究                         開始／重新研究
     | 資料日期                     展開資料與研究紀錄
     | 已發布研究 / 篩選候選         搜尋、產業、排序
     | 股票       營收年增    營益率    負債比    成交額
     | 勾選比較   ...        ...       ...       開啟
     | 2–3 檔比較操作列

導覽 | 返回候選                 切換個股
     | 股票名稱、狀態、收藏／略過
     | 重點總覽 / 證據查核 / 風險與失效 / 研究紀錄
```

## 對照 brief 後的修正

捨棄一般金融 dashboard 常見的大盤卡片、紅綠漲跌和折線圖，因為目前 API 沒有行情服務。視覺重點集中在真實財務對照表。初次開啟就顯示 A 的候選明細並標明尚未研究；B 已發布研究與 A 候選分開，排序只調整閱讀順序，不改後端研究排名或投資偏好。

搜尋只涵蓋這一份已取得的候選，產業篩選不冒充重新硬篩選；比較最多三檔同一份資料，負債比數字低不等於安全保證。模擬研究保留標示與原始內容，不偽造成正式中文投資論點。

追蹤首頁採摘要清單，依論點狀態快速查看需重新評估的股票，再進入版本差異與重查。原本的回饋、證據來源、失效條件、等待與失敗處理均保留。

## 投資人流程複查後的改善

再次實際走完完整流程後，補上搜尋範圍切換、比較內閱讀研究、單一查證面板與返回焦點、示範來源辨識、跨分頁收藏確認，以及追蹤頁的收藏理由與筆記。沒有新增市場或模型資料。完整的問題對照與驗證證據見 [投資人流程檢查](INVESTOR_FLOW_REVIEW.md)。
