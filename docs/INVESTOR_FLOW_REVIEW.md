# 投資人完整操作流程檢查

2026-10-13（Asia/Taipei）。在 `localhost:5173` 實際操作現有 mock API，依序完成找股票、比較、查證、收藏追蹤。這是產品操作驗證，不是股票投資評估或真人訪談。

## 操作情境與修正

| 步驟 | 實際遇到的問題 | 已實作的改善 |
| --- | --- | --- |
| 找股票 | 在「已發布研究」搜尋藥華藥顯示空白結果，看不出它其實在 A 的候選中；產業篩選也可能把搜尋結果藏起來。 | 明示只搜尋本輪候選；提供切換到有結果的候選範圍，或清除產業篩選的入口，保留原搜尋文字。未提供全市場搜尋。 |
| 比較 | 選南亞科、創新服務後，比較表沒有直接閱讀研究的入口，指標也缺解釋。 | 各股票可直接閱讀研究，選取列可逐檔移除；加入四項指標、單位與期間的說明。返回候選時保留選取並恢復比較按鈕焦點。 |
| 查數據 | 比較面板另開來源面板，立即按 Escape 曾關掉底下比較、留下來源，造成上下文混亂。 | 改為單一 Dialog 內切換來源，明示股票名稱／代號；「返回比較，保留已選股票」還原原來源按鈕焦點。Escape 關閉整個檢視器，候選選取仍保留。 |
| 查研究證據 | Mock 的 `example.invalid` 來源看似能開啟，容易誤認為正式查證。 | `.invalid` 來源明示示範且不產生連結；研究頁另標示模擬論點與查證狀態。真實 HTTP(S) 來源仍保留連結。量化查證方法直接可讀，公式與原始輸入按需展開。 |
| 收藏 | 從風險分頁收藏後，權重回饋確認藏在總覽，也缺少直接查看該股票追蹤的入口。 | 成功確認置於所有分頁都看得到的位置；提供「查看追蹤與筆記」和成功提示入口；候選與比較同步標示已收藏。確認後端成功才顯示完成。 |
| 追蹤 | 找不到自己當時的理由、筆記；只有一版卻顯示版本比較控制，也看不出目前是否自動重查。 | 讀取後端最近一次 SAVE 回饋，呈現理由、筆記與時間。只有一版時說明尚待後續資料，不顯示無效比較控制。排程未啟用時明確告知需要後續重查。 |
| 操作細節 | 比較按鈕的 hover 樣式造成文字對比不足。 | 比較列專用 hover 色彩，維持可讀對比。 |

收藏筆記使用現有 feedback history，不新增前端假資料或後端儲存格式。已追蹤的股票可補充新研究回饋；依後端契約，這不代表替換原始追蹤論點。曾移除的股票不因舊 SAVE 紀錄而永久禁用收藏。

## 實際驗證

- 搜尋藥華藥 → 切換範圍保留搜尋；產業隱藏結果 → 清除產業保留搜尋。
- 南亞科與創新服務並排 → 查看量化來源 → 返回比較與原焦點 → 直接閱讀南亞科 → 返回候選保留比較選取。
- 查證面板同時只存在一個 Dialog，Escape 一次關閉；比對南亞科量化來源映射至 API 提供的 MOPS 網址。未開啟或人工核驗外部 MOPS 文件，不宣稱來源內容已驗真。
- 在南亞科的風險分頁收藏，選「財務穩健」並填寫筆記；確認權重回饋可見、跳轉到對應追蹤；重新載入後仍由後端讀到理由與筆記。這段驗收只產生一次 feedback POST。
- 完整流程腳本 16 個斷言通過，無 JavaScript page error；單元測試 11 個、獨立使用者的完整 API 整合測試 1 條、TypeScript／production build 通過。
- 320、390、1024、1440 px 寬度均完成比較 → 來源 → 研究操作；候選頁、追蹤頁及來源檢視器沒有頁面水平溢出。桌面追蹤、390／1440 比較與來源、手機研究與追蹤共 7 個狀態經 axe-core 掃描 WCAG 2 A/AA + 2.1 A/AA，修正 hover 對比後為 0 violations；不等於螢幕閱讀器或實體手機認證。

此輪在 mock 的 `demo-user` 新增創新服務與南亞科收藏，分別用於改善前、改善後操作驗證；沒有自動刪除收藏或重設使用者回饋。這些回饋會實際影響下一次 mock 研究權重。

瀏覽器腳本與截圖在 Git 忽略的 `output/playwright/investor-*`：`investor-after.js` 是完整流程，`investor-responsive.js` 是各寬度及 axe 檢查。完整流程會寫入收藏，重跑時應使用獨立測試使用者，避免重複回饋。

## 仍有的產品邊界

候選來自目前取得的 A 資料；沒有全市場搜尋、即時價格或走勢。Mock 研究保留原始 `[MOCK]` 文字，不能代替正式研究。收藏記憶體資料在 mock 後端重啟後可能消失；頁面重新載入通過不代表持久化儲存驗收。正式模型、每日排程、真人試用與真實事件追蹤仍需另外驗證，詳見 [整體驗收紀錄](FRONTEND_VALIDATION.md)。
