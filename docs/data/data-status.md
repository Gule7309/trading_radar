## 一句話總結

2015-01 至今的上市櫃**行情、法人、融資融券、月營收、季財報、除權息、處置／注意股、下市清單**都已補齊，
存在**單一 SQLite 檔**（約 1.35 GB），每個交易日晚上自動增量更新；已能輸出可追溯來源的
**Candidate + Evidence JSON** 給 Agent 與 Frontend。

## 資料品質（已驗證）

- **回補完成**：融資融券、三大法人買進／賣出明細在上市、上櫃的缺口皆為 0；2015 年起法人明細欄位無 NULL。
- **完整性**：`PRAGMA quick_check` = ok；備份與原始資料庫的 18 張表筆數完全一致。
- **交叉驗證**（Screening 時自動執行）：
  - 營業利益率、負債比：用原始金額重算，與資料表內的比率**全部一致**（2026Q2 一般業 1,934 檔，差異 0）。
  - 營收 YoY：用營收重算，與來源提供的 YoY 比對；2026-08 有 **6 檔差異超過 0.1 個百分點**（多半是營收重編或基期不同），
    這些股票不會進入排名。
- **公開性**：全部來自 TWSE、TPEx、MOPS 公開資料。

## 目前**沒有**的資料

以下刻意不在此階段處理，需要時另案評估：

- 盤中／即時行情、分鐘 K、五檔。
- 新聞、重大訊息、法說會內容（屬 Agent 層的 Evidence 來源，不在資料層）。
- 興櫃股票、ETF 的基本面。
- 歷史上每一天的股票 universe 快照（`stock_universe_history` 只有 2026-07-31 一份）。
- 財報的實際公告日（目前使用保守的估計可用日）。
- 技術指標（均線、RSI 等）——需要時由使用端從 `daily_prices` 計算。
